How the AI works on Cloudflare Workers AI

Each request goes to a Cloudflare Worker, which asks a Clef decision model on Workers AI. Clef doesn't write text. It answers typed questions with a probability for every allowed option.

Every part of your avatar is one question: hair length, hair colour, glasses, beard and so on, each with the exact values this library can draw. One call answers all of them in a few hundred milliseconds, so the result can only ever contain valid traits.

Text uses Clef flash. Each question also has a "keep" option, and a part only changes when the model is confident the request is about it (keep under 20%). Photos use Clef omni, which reads the image and answers the same questions. Skin tone is a score question, so it can land between palette steps.

Your photo is resized in your browser (which also removes location and camera data), sent once to the Worker, analysed, and discarded. This site doesn't store or log it, and Workers AI lists Clef as zero data retention. Only the resulting traits come back.
